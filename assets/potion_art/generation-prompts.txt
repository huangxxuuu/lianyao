AI Passport Potion Game - Stable Pixel Art Prompt Set v1

Shared visual specification
Use case: stylized-concept
Asset type: embedded game item sprite atlas for a 240x320 LCD
Primary request: create crisp, readable pixel-art inventory sprites for an original pocket alchemy game
Style/medium: hand-authored 16-bit-era pixel art, hard square pixels, no anti-aliasing, no gradients, limited color ramps, one-pixel dark outline and selective one-pixel highlights
Composition/framing: every item is centered in its own equal square cell, identical scale and viewing angle, at least 10% clear padding around every silhouette, no overlap between cells
Lighting/mood: soft magical glow expressed only with clustered pixels; mysterious, warm and playful
Color palette: deep aubergine outlines, muted teal, moss green, copper, amber, moon blue and restrained magenta; maximum about 12 colors per sprite
Materials/textures: readable at 32x32 pixels, chunky silhouettes and distinct material texture
Text: none
Constraints: exactly the requested grid and item order; transparent background; each cell contains exactly one isolated item; consistent outline, scale, lighting and pixel density; original design; production-ready sprite sheet
Avoid: words, letters, numbers, labels, UI frames, cell borders, watermark, logo, characters, hands, scenery, cast shadows outside each cell, smooth vector edges, painterly brushwork, blur, noise, 3D render, photorealism
